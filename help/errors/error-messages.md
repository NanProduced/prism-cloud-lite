# 错误码对照表

当系统操作失败或设备出现异常时，通常会显示一个形如 `CORE-XXXX` 的错误码。以下是常见错误码的含义及建议处理方式。

## 1. 认证与账户类 (10xx)

| 错误码 | 描述 | 建议操作 |
| :--- | :--- | :--- |
| `CORE-1001` | 登录过期 | 请重新登录账号。 |
| `CORE-1002` | 账号或密码错误 | 请检查输入，或联系管理员重置密码。 |
| `CORE-1005` | 权限不足 | 您尝试访问的内容超出了您的角色权限。 |

## 2. 设备与配额类 (20xx)

| 错误码 | 描述 | 建议操作 |
| :--- | :--- | :--- |
| `CORE-2008` | 设备配额不足 | 无法添加新设备，请升级套餐或删除旧设备。 |
| `CORE-2202` | 自定义字段超限 | 您创建了过多的设备标签或字段。 |
| `CORE-2009` | 截图不存在 | 该设备尚未上报截图，或截图已被清理。 |

## 3. 节目与发布类 (28xx)

| 错误码 | 描述 | 建议操作 |
| :--- | :--- | :--- |
| `CORE-2808` | 节目删除被阻止 | 该节目正被某排程使用，请先从排程中移除它。 |
| `CORE-2810` | 发布指令超时 | 设备可能处于极差的网络环境下。 |

---
*注：本表仅包含常见用户端错误。如果您遇到了未列出的错误码，请记录代码并联系技术支持。*
