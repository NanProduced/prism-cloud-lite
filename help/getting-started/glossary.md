# 术语表

为了帮助您更好地理解和使用 Prism Cloud Lite，我们对系统中的核心概念进行了统一定义。

## 1. 核心对象

| 术语 | 说明 |
| :--- | :--- |
| **设备 (Device)** | 最终展示内容的终端硬件（如播放盒、显示屏）。设备需要先在系统中添加并保持在线，才能接收指令或更新内容。 |
| **素材 (Media)** | 构成节目的基础媒体文件，如图片（JPG/PNG）、视频（MP4）等。您需要先将素材上传到“素材库”中。 |
| **节目 (Program)** | 包含了一个或多个素材及其排版布局的容器。节目是“播什么”的最小单位。 |
| **排程 (Schedule)** | 规定了“什么时候播”的规则集合，包括日期范围、具体时间段、星期循环等。 |

## 2. 常用操作

| 术语 | 说明 |
| :--- | :--- |
| **发布 (Publish)** | 将编辑好的节目或排程真正发送到设备上的过程。只有执行了发布，设备端才会更新播放内容。 |
| **秒传 (Instant Upload)** | 当您上传一个素材时，如果系统中已经存在完全相同的文件，系统将瞬间完成“上传”，无需等待网络传输。 |
| **转码 (Transcoding)** | 将原始视频转换为更适合在各类播放终端上流畅播放的格式。 |
| **绑定 (Binding)** | 建立节目/排程与设备之间的关联关系。 |

## 3. 状态说明

| 术语 | 说明 |
| :--- | :--- |
| **在线 (Online)** | 设备当前已连接到云端，可以实时接收操作指令。 |
| **离线 (Offline)** | 设备与云端连接断开，但它通常会继续按照最后一次收到的计划进行本地播放。 |
| **休眠 (Sleep)** | 设备处于省电模式，屏幕可能关闭，但网络模块可能仍然在线。 |
| **草稿 (Draft)** | 正在编辑中且尚未发布的版本，不会影响设备当前的播放内容。 |
