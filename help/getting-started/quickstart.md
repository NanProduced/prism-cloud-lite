# 快速上手指南

本指南将带您在 5 分钟内完成从“初次登录”到“成功发布节目”的全过程。

## 准备工作
- 确保您已拥有 Prism Cloud Lite 账号。
- 确保您的播放设备已接通电源并连接到互联网。

---

## 第 1 步：登录平台
1. 打开浏览器，访问 Prism Cloud Lite 官网地址。
2. 输入您的账号和密码。
3. 点击“登录”进入仪表盘（Dashboard）。

## 第 2 步：添加您的第一台设备
1. 在左侧菜单点击 **设备管理**。
2. 点击右上角的 **+ 新增设备**。
3. 输入设备名称，并记录系统生成的 **设备账号** 和 **初始密码**（用于在物理设备上登录）。
4. 确认后，您的设备将出现在列表中，状态显示为“离线”。

## 第 3 步：上传媒体素材
1. 点击左侧菜单的 **素材库**。
2. 点击 **上传素材** 按钮。
3. 选择您电脑中的图片或视频文件。
4. 等待上传进度条完成。如果是视频，系统可能会自动开始“转码”以确保播放流畅。

## 第 4 步：创建并编辑节目
1. 点击左侧菜单的 **节目管理**。
2. 点击 **+ 新建节目**，选择适合您屏幕的分辨率（如 1920x1080）。
3. 在编辑器中，将刚才上传好的素材拖入画布。
4. 调整素材的大小、位置和播放时长。
5. 点击右上角的 **保存草稿**。

## 第 5 步：发布内容到设备
1. 在节目编辑页面或列表页面，点击 **发布** 按钮。
2. 在弹出的窗口中，勾选您刚才添加的设备。
3. 点击 **确定发布**。
4. 系统将显示“下发成功”。当设备在线时，它会自动下载最新素材并开始播放。

## 第 6 步：监控播放状态
1. 返回 **仪表盘** 或 **设备列表**。
2. 查看设备的“在线状态”和“最新截图”。
3. 看到设备截图更新为您刚才发布的节目内容，即表示播放成功！
