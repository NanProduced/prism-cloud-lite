# 创建与编辑节目

节目是您展示给受众的核心内容。本文将教您如何创建一个新节目并添加素材。

## 你将完成什么
创建一个具有特定分辨率的节目，并在其中排布图片或视频素材。

## 操作步骤
1. **新建节目**：
   - 点击左侧导航栏的 **节目管理**。
   - 点击右上角的 **+ 新建节目**。
   - 在弹窗中输入节目名称，并选择分辨率。
     - *提示：请务必选择与您的物理显示屏一致的分辨率（如 1920x1080），否则播放时可能出现拉伸或黑边。*
2. **进入编辑器**：点击保存后，您将进入可视化编辑器。
3. **添加素材**：
   - 在左侧素材面板中，找到您之前上传的素材。
   - 将素材**拖拽**到中间的画布区域。
4. **调整布局**：
   - 选中素材，通过拖动边缘调整其大小。
   - 您可以设置素材的“填充方式”（拉伸、适应或裁剪）。
5. **设置时长**：
   - 对于图片，您可以在右侧属性面板设置其“持续时间”（秒）。
   - 对于视频，系统默认使用视频原始时长。
6. **保存与预览**：
   - 点击右上角的 **保存草稿**。
   - 点击 **预览** 可以查看在真实屏幕上的模拟效果。

## 结果确认
- 返回节目列表，您将看到刚才创建的节目，状态为“草稿”。
- 列表会显示该节目的最新修改时间和封面。

## 常见问题
- **Q: 我的屏幕是竖着的，怎么设置？**
  - A: 在新建节目时，自定义分辨率为 1080x1920 即可。
- **Q: 一个节目里可以放多个视频吗？**
  - A: 取决于您的设备能力，通常建议一个节目画面中只包含一个主要视频区域，以保证播放稳定性。
- **Q: 为什么保存不了？**
  - A: 请检查网络连接，或确认您是否在同一个账号的其他窗口中也开启了该节目的编辑器。
