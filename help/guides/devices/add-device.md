# 如何添加设备

本文将介绍如何将一台新的播放终端添加到 Prism Cloud Lite 平台进行管理。

## 你将完成什么
在系统中创建一个设备身份，并获得用于物理设备连接的凭据。

## 前置条件
- 您的账户拥有足够的“设备配额”。
- 如果配额不足，请前往 [套餐与额度](../billing-and-quota/tiers.md) 查看如何升级。

## 操作步骤
1. **进入设备页面**：在左侧导航栏点击 **设备管理**。
2. **启动添加流程**：点击页面右上角的蓝色按钮 **+ 新增设备**。
3. **填写基础信息**：
   - **设备名称**：为您的设备起一个易于识别的名字（如“大厅 01 号屏”）。
   - **描述**：可选填，用于标注位置或用途。
4. **生成凭据**：点击“提交”后，系统会弹出一个窗口，显示：
   - **设备账号 (Device Account)**
   - **初始密码 (Initial Password)**
5. **记录凭据**：**重要！** 请务必立即复制或记录下这对账号密码。出于安全考虑，密码在关闭窗口后将无法再次完整查看。
6. **物理设备连接**：在您的物理播放器上启动 Prism 客户端，输入刚才获得的账号和密码进行登录。

## 结果确认
- 返回系统的 **设备列表**。
- 此时该设备应出现在列表中。
- 一旦物理设备登录成功并联网，其“在线状态”图标将由灰色（离线）变为绿色（在线）。

## 常见问题
- **Q: 为什么提示“配额不足”？**
  - A: 您的当前套餐支持的设备数量已达上限。您可以删除不再使用的旧设备，或升级您的套餐。
- **Q: 忘记了设备密码怎么办？**
  - A: 您可以在设备详情页找到“重置密码”选项（需管理员权限）。
- **Q: 设备已经登录但状态依然显示离线？**
  - A: 请检查物理设备的网络连接，或确认防火墙是否允许访问云端 API 地址。
