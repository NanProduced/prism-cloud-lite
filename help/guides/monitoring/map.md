# 地图监控与告警

对于拥有大量跨区域设备的用户，地图视图提供了直观的全局掌控能力。

## 你将完成什么
在地图上定位设备位置，并查看全国范围内的异常告警。

## 操作步骤
1. **切换到地图模式**：在首页 **仪表盘** 顶部，将视图切换为 **地图模式**。
2. **查看设备分布**：
   - 地图上的点代表设备位置。
   - 蓝色点表示一切正常。
   - 红色或橙色点表示该区域有设备处于离线或异常状态。
3. **点击查看详情**：点击地图上的某个点，会弹出精简信息框，显示该设备的名称、状态和当前播放的节目。
4. **处理告警**：
   - 点击右上角的 **告警列表**。
   - 查看近期的异常记录（如“设备非正常离线”、“播放内容冲突”等）。
5. **设置位置**：
   - 如果设备位置不准确，您可以在 **设备管理 > 编辑** 中手动设置地理坐标，或开启设备的 GPS 自动定位功能。

## 结果确认
- 确保所有已安装的设备都能在地图上找到对应位置。
- 异常设备处理完毕后，地图上的红色点会自动恢复为蓝色。

## 常见问题
- **Q: 为什么有些设备重叠在一起了？**
  - A: 当多个设备位于同一个建筑（如商场）时，您可以放大地图查看具体位置。
- **Q: 告警信息会发送到手机吗？**
  - A: 您可以在 **个人设置 > 通知中心** 中绑定微信或邮箱，接收实时的异常告警。
- **Q: 地图加载不出来？**
  - A: 请检查您的网络是否可以访问主流地图服务（如高德或 MapTiler），或尝试刷新页面。
